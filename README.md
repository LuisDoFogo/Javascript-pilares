# Introducción a JavaScript

Actividad escolar para practicar conceptos básicos de JavaScript: variables, tipos de datos y operadores aritméticos.

## Archivos

- `index.html`: página en español con la explicación y las tres actividades.
- `styles.css`: estilos sencillos y adaptables a computadora y celular.
- `script.js`: código de las actividades 1 y 2.

## Cómo abrir el proyecto

1. Abre esta carpeta en Visual Studio Code.
2. Abre `index.html` con la extensión **Live Server**. Haz clic derecho en el archivo y selecciona **Open with Live Server**.
3. Para ver los resultados de las actividades 1 y 2, abre las herramientas de desarrollador del navegador con **F12** y selecciona **Console**.
4. Para la actividad 3, copia su ejemplo desde la página, pégalo en **Console** y presiona **Enter**. El resultado es `8`.
