Introducción a JavaScript

Conceptos básicos, variables y operaciones

¿Qué es JavaScript?

JavaScript es un lenguaje de programación que permite agregar interactividad a las páginas web. También sirve para realizar operaciones, trabajar con datos y ejecutar instrucciones.

Actividad 1: Variables y tipos de datos

Declaramos un nombre y una edad. El operador typeof permite consultar el tipo de dato de cada variable.

let nombre = "Juan";
let edad = 25;

console.log(typeof nombre);
console.log(typeof edad);

En la consola aparecerán string y number.

Actividad 2: Operadores aritméticos

Con los números 5 y 3, el programa realiza suma, resta, multiplicación, división y módulo (el residuo de una división).

let num1 = 5;
let num2 = 3;

console.log("Suma:", num1 + num2);
console.log("Resta:", num1 - num2);
console.log("Multiplicación:", num1 * num2);
console.log("División:", num1 / num2);
console.log("Módulo:", num1 % num2);

La división se muestra sin redondear: 1.6666666666666667.

Actividad 3: Sumar dos números

Para ejecutar este ejemplo manualmente, abre la página en el navegador, presiona F12, selecciona la pestaña Console, copia el código y pégalo allí. Presiona Enter; el resultado será 8.

let num1 = 5;
let num2 = 3;
console.log(num1 + num2);
